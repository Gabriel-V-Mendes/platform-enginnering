# Bem-vindo ao IDP — Platform Engineering

Esta é a documentação oficial da **Internal Developer Platform (IDP)**, gerada através do padrão **Docs-as-Code** com MkDocs.

Nossa plataforma consolida automação, templates padronizados (Golden Paths) e observabilidade, tudo acessível via portal self-service.

## O que você encontra aqui

| Seção | Descrição |
|---|---|
| [Arquitetura](architecture.md) | Visão geral dos componentes e integração entre eles |
| [Golden Paths](golden-paths.md) | Templates para criar microsserviços padronizados em segundos |

## Primeiros Passos

1. Acesse o portal Backstage em `http://localhost:7007`
2. Navegue até **Create** para criar um novo serviço usando um Golden Path
3. Explore o **Software Catalog** para ver todos os serviços registrados
